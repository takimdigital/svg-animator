# Motion DNA v0.2 — independent release audit

## Challenge: what would make a false claim look convincing?

We treated every `PASS` and every extracted motion fact as potentially wrong.

| Angle / adverse input | Finding | Correction / gate |
|---|---|---|
| Missing all observed targets, `ignore_missing=True` | Old comparator could return PASS with `coverage=0` | No comparison evidence => INCONCLUSIVE; missing requested elements => FAIL |
| Candidate supplies only one matching frame | Old comparator compared timestamp intersection and could PASS incomplete timeline | All reference/candidate sample times must align for PASS; INCONCLUSIVE otherwise |
| Moving reference element missing but shared background remains | Old auto-targets selected only intersections and could omit vanished elements | Default target selection covers every reference element; missing => FAIL |
| Symmetric element rotates but bbox unchanged | Old geometry comparison could certify unchanged bbox | Trace records relative SVG CTM; compare a/b/c/d rotation, skew and scale coefficients |
| Multiple source animations on same target | Reconstruction collapsed duplicate targets, silently omitting an animation | Reject ambiguous/mixed recipes |
| Invalid NaN tolerances | Python float NaN could deactivate threshold comparisons | Require finite tolerance in [0,1] |
| Installer `--force` with an existing backup | Could partially install before detecting late backup collision | Preflight all backup collisions before writing |
| CSS/SMIL untrusted SVG | Browser exposure if active or remote assets allowed | Reject script, handlers, DTD, foreignObject, external href and imported CSS; block network |
| Rotation distance silently changed | Original reconstruction hardcoded 360° even for 180° input | Refuse non-full-turn and nonlinear recipes rather than substituting motion |
| Spline easing silently linearized | Original pulse variation did not copy key splines | Explicitly refuse spline, discrete or paced variation recipes |
| Oversize SVG parsed before size guard | Browser path parsed input before calling static inspector with 4MB limit | Run size-checked static inspect before any browser-path SVG parsing |
| Browser checks silently skipped in CI | Previous workflow didn't install Chromium | Separate browser job explicitly installs/launches Chromium and rejects browser-test skips |
| README generated by a page builder | Hand-inserted README section can be overwritten by rebuild | Stable agent routing in SKILL and references; README is not the only discovery path |

## Evidence and limits

The local suite is deterministic at sampled timestamps, except unavoidable Chromium interpolation differences. It proves selected observable properties, not continuous-time or design equivalence. State comparison now covers CTM linear coefficients where present. Opacity mode deliberately does not compare geometry or artwork. It does **not** inspect remote websites, GIFs, videos, animation source in embedded iframes, advanced CSS selector graphs, or dependencies fetched at runtime. These are future research routes, not promised capabilities.

## Merge conditions

1. Every original CI gate succeeds, preserving existing generator semantics and byte-reproducible examples.
2. Motion DNA static and browser tests succeed with no browser skips.
3. The original SVG linter accepts the generated variation.
4. Repository docs, import paths, and CLI commands work from the repository root.
5. Review security posture before accepting arbitrary external SVGs. This tool is *not* a hardened adversarial sandbox.
